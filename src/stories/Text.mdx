# Text

디자인 토큰 `typo-*` 유틸리티를 `variant`로 매핑한 polymorphic 텍스트 컴포넌트입니다.
`Box`를 기반으로 하며, 기본 태그는 `span`입니다.

```tsx
import { Text } from '@/shared/ui/text';

<Text variant="heading-xl">제목</Text>
<Text variant="body-lg" className="text-text-medium">
  본문
</Text>
<Text variant="display-lg" as="h1">
  히어로
</Text>
```
