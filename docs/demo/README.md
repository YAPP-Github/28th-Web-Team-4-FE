# 기능별 데모 영상

[서비스 소개로 돌아가기](../../README.md#주요-기능)

배포 서비스의 실제 화면을 촬영한 데모 14편입니다. 메인 README에서는 GitHub에 첨부한 대표 8편을 바로 재생할 수 있고, 전체 영상은 [데모 갤러리](https://yapp-github.github.io/adlib/demo/)에서 확인할 수 있습니다.

MP4 원본은 [adlib 저장소의 public/demo](https://github.com/YAPP-Github/adlib/tree/main/public/demo)에서 관리합니다. 이 저장소에는 MP4를 중복 보관하지 않습니다.

## 파일 관리

- MP4는 H.264, 1280×800, 25fps, 무음입니다.
- `posters/`에는 영상 5편의 썸네일이, `gifs/`에는 영상 6편의 미리보기가 보관되어 있습니다.
- 영상 교체 시 adlib 저장소의 MP4·미리보기 이미지와 영상 목록을 갱신합니다.
- 메인 README에 표시하는 대표 영상도 바꿀 때는 MP4를 GitHub에 다시 첨부하고 README의 해당 URL을 갱신합니다.
- 화면 변화가 없는 대기 일부를 편집했습니다. 영상 길이가 실제 처리 시간을 의미하지는 않습니다.
