## 파일 관리

- MP4는 H.264, 1280×800, 25fps, 무음입니다.
- `posters/`에는 README에서 사용하는 대표 영상 5편의 썸네일이 있습니다.
- `gifs/`에는 README에서 바로 재생하는 대표 영상 6편의 GIF가 있습니다.
- README의 썸네일과 영상 링크는 이 폴더의 MP4 파일을 가리킵니다.
- 영상을 교체할 때는 해당 썸네일과 README의 길이 표기도 함께 갱신합니다.
- 화면 변화가 없는 대기 일부를 편집했습니다. 영상 길이가 실제 처리 시간을 의미하지는 않습니다.
